# 💊 PhiliGo

**Gamified TB treatment adherence app for children in Eswatini.**

Built with HTML, CSS & vanilla JavaScript. No frameworks, no build step, no backend.

## 🎮 Features

- **4 Real Games:** Pill Runner · Pill Match · Memory Cards · TB Quiz
- **Adherence tracker** — daily pill check-in with rewards
- **Achievements** — 12 unlockable badges
- **Parent dashboard** — PIN protected, adherence charts, education
- **PWA** — installable on Android, works offline
- **Sound effects** — generated via Web Audio API (no files)
- **Haptics** — vibration on supported devices
- **Dark mode** — toggle in settings
- **Zero dependencies** — pure vanilla JS
